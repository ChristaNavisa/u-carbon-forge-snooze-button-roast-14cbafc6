One line roasting an alarm clock that rings at 6 AM on a Saturday morning.
The twist: the alarm is the one acting employed — screaming like it is late
for a shift its owner never had.

Entry: "Saturday 6 AM, my alarm screamed like it was late for a job I don't even have."

Run `main.ts` with Node; it writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
